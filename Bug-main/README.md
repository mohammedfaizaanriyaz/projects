# Tech Tycoons - Static Website

A static website for the Tech Tycoons college technical club, built with HTML, CSS, and vanilla JavaScript. This repository is intended for the "Code Revive" debugging competition, where participants must inspect, debug, and restore the website's functionality.

## Pages

The website includes the following pages:
- **Home** - Main landing page with hero section
- **Events** - Upcoming technical events with registration UI
- **Members** - Member directory with cards
- **Leaderboard** - Member points ranking
- **Resources** - Learning resources section
- **About** - Club information and mission
- **Contact** - Contact form

## Features

- Responsive navbar that adapts to screen size
- Hero section with welcome message
- Event display with cards
- Member cards with avatars and roles
- Basic styling consistent throughout

## Running the Project

Open `index.html` directly in any modern browser. No server or build setup is required.

## Competition Note

This website has been intentionally modified for the Code Revive debugging competition. Participants are expected to inspect the code, identify issues, and restore full functionality. The site appears mostly complete but contains realistic bugs across event handling, member management, user interface, and accessibility.

Good luck debugging!
